# PKLaboratory

Aplicación web en R Shiny para la simulación y visualización de modelos
farmacocinéticos con mrgsolve y para su ajuste a datos poblacionales e
individuales con nlme.

Permite simular los modelos de la biblioteca de
mrgsolve con distintas pautas de dosificación, crear modelos propios desde
un editor de código o un asistente por componentes y compartirlos con otros
usuarios, y estimar los parámetros de un modelo a partir de un CSV con
concentraciones observadas, mediante modelos de efectos mixtos o ajustes
individuales por paciente.

Disponible en: https://pklaboratory.shinyapps.io/pklaboratory/
